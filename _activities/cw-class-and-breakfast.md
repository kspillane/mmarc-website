Join us every Saturday morning for breakfast and a Morse code (CW) class!

- **8:00 AM** - Breakfast
- **9:00 AM** - Morse Code Class

**Location:**  
SSM Health St. Mary's Hospital  
2505 Mission Drive, Jefferson City, MO

**Directions:**
1. Take the 3rd roundabout and turn right into the parking lot with the "OUT-PATIENT ENTRANCE" sign.
2. Enter through the Out-Patient Entrance, then turn left to access the elevators or stairs.
3. Go DOWN one floor.
4. Walk straight down the hall into the cafeteria.

We are usually the only ones dining at that hour, so it's easy to find us!
