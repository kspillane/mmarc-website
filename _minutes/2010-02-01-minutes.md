15th. Judy, KDØAJF questioned if there would be any exercises coming up that newly
certified people can participate in. Joe will look into this, but nothing is currently planned.

CW Classes: Tom, NØSS, reports that the advanced class is going well. Tom took some
orders for some battery powered amplifiers for the class members. This class meets before
breakfast at 6:45am every Saturday morning at Mel’s Country Café.

Bill, W4RK, reports that the intermediate class is also going well with both students and
instructors having fun. This class meets after breakfast from 9-10am at Mel’s.

Kent, K9ZTV, added that the new beginning class is still available for those who know little
to nothing and would like to learn. This class meets at 10am after breakfast and the slow
speed class.
